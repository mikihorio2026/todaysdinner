# プロダクトのタイトル
- 今日のばんごはん

## プロダクトの紹介

- メイン食材を選ぶ
- 組み合わせる食材を選ぶ
- 2つの食材を使ったレシピをランダム表示

自分でスマホから使いたかったのでSPデザインまんま真ん中に持ってきました。

## 工夫した点、こだわった点

☆ユースケース
いつも２つの食材でワード検索している
ストックしている材料はだいたいいつも同じ
気に入ったレシピは繰り返し使う

☆ペイン
TikTokはそもそもそういう使い方を想定してないw
おきにいり一覧のサムネを見てもどのレシピかわからん
決まった食材でのお気に入りレシピ複数から適当に選んで作るのに毎回検索からやるのが果てしなくダルい
・・・から作りました笑

☆こだわった点

1.ボタンを押さなくても食材を選択しただけでサクッと先に進む
2.ランダム表示で考える労力を省きつつ「気分じゃない」と思ったときに同じ組み合わせで今見ているレシピ以外のレシピをランダム表示する「他のレシピを見る」ボタン
3.組み合わせからやりなおしたい人は「選び直す」

だたし2と3は自分で書くのが難しすぎて「こうしたい」とAIに伝えて書いてもらった後、これはどういうコードですか!?!? ってずっと説明してもらいながら理解しようとしています（現在進行形）むずい。

授業で習ったランダムなんちゃらと、if構文だけはなんとか書きました。
